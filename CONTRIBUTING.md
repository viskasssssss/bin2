# Contributing to bin2

Thank you for your interest in contributing to `bin2`!

Contributions of all kinds are welcome, including bug reports, feature suggestions, documentation improvements, and code changes.

## Reporting Bugs

If you find a bug, please open a GitHub issue and include:

- A clear description of the problem.
- Steps to reproduce it.
- The expected and actual behavior.
- A minimal code example, if possible.

## Suggesting Features

Feature suggestions are welcome. Please explain the problem you want to solve and why the proposed feature would be useful.

## Submitting Changes

1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes and add or update examples when appropriate.
4. Run the available checks and tests.
5. Open a pull request describing your changes.

## Code Guidelines

- Follow standard Rust formatting using `cargo fmt`.
- Make sure the project builds with `cargo check`.
- Run the test suite with `cargo test`.
- Keep changes focused and document any relevant API changes.

## Questions

If you have questions or need clarification, feel free to open a GitHub issue.

Thank you for helping improve `bin2`!
